How to practice practice guidance
Sit comfortably. Notice the breath where it touches near the nostrils. Count each in-and-out cycle from one to eight, then restart. When attention wanders, return without commentary. If the breath becomes faint, wait rather than forcing it.

Data

Everything lives in this browser's localStorage (key jhanaTracker.v2). Browser data can be cleared by the OS or the user — export regularly. Data is not encrypted and never leaves this device unless you configure an AI provider or export it yourself.

AI provider (optional)

By default the Journal uses a local, deterministic parser — nothing leaves the device. If you configure a provider, journal text is sent to that endpoint when you press “Create draft”. The key is stored only in this browser's localStorage, in plain text.

If the provider fails or returns malformed output, the app falls back to the local parser automatically.
